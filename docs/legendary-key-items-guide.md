# 전설 포켓몬 키 아이템 공략표 (Myths and Legends v1.0.5)

> **사용법**: 키 아이템을 **인벤토리에 소지**하고 해당 바이옴에 있으면 전설이 주변에 스폰될 수 있다 (스폰 주기 검사 약 2분 30초, 즉시 보장 아님).
> 스폰 성공(포획) 시 키 아이템은 소모된다. 키 아이템은 구조물 상자·고고학·트라이얼 챔버 금고 등에서 획득 ([README](../server-pack/README.md) 참고).
>
> 키 아이템이 2개 적힌 전설은 **둘 중 하나만** 있으면 된다. 바이옴 뒤 `ᵀ` = Terralith 바이옴(모드팩 포함). 확인: 아이템 소지 후 `/checkspawn ultra-rare`
